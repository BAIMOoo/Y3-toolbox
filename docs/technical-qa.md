# 技术问答使用说明

`技术问答` 是工具箱中的独立功能模块，不属于 `Agent 任务中心`。它面向 Y3 Editor 2.0 技术问题，使用服务端问答运行时生成回答，并把检索到的文档、案例或已审核知识作为证据。即使问题已有记录，也不会只返回检索内容；每个产生答案的回合都会经过模型综合。

## 功能范围

- 固定版本为 `Y3 Editor 2.0`，不要求也不接受其他编辑器版本、构建号或 lualib 分支信息。
- `ECA / 编辑器` 用于事件、条件、动作、对象配置和编辑器行为。
- `Lua / y3-lualib` 用于 API 用法、运行行为、报错与脚本侧排查。
- 回答可能包含引用来源。引用会标明标题、来源位置、证据权威级别和 `Y3 2.0` 范围。
- 新版答案可能在正文下方显示依据片段标签：`对话上下文`、`来源支持` 或 `推断`。这些标签不改变可复制的纯文本答案；`知识不可用`、`来源不可用` 等提示会单独显示。
- 当证据不足、问题有歧义或请求超出范围时，服务会要求补充信息或明确拒绝，不会用未经支持的内容补齐答案。

## 提问与诊断附件

在顶部选择问题所属领域，输入问题后提交。一次只生成一个回答；回答完成后可以继续追问。同一对话会续接服务端 Codex Runtime 上下文，新建对话不会继承旧对话。切换到工具箱其他模块不会清空当前问答历史。

可以在提交前添加明确选择的诊断材料：

- 日志或 Trace：`.log`、`.trace`、`.txt`、`.json`，单个文件不超过 2 MiB。
- 截图：PNG、JPEG、WebP，单张不超过 8 MiB。
- 每次提问最多 5 个附件，总大小不超过 16 MiB。
- 空文件、重复文件、包含本地路径的文件名和不支持的格式会被拒绝。

附件只用于本次显式诊断，不会授予服务访问项目目录或其他本地文件的能力。上传内容由服务端按保留策略清理。

## 回答状态与恢复

- `检索中`、`生成中`：服务正在核对证据或生成回答，可以取消。
- `已完成`：答案已结束；有引用时可在答案下方检查来源。
- `需要补充`：问题缺少必要上下文，按提示补充后重新提问。
- `证据不足` 或 `已拒绝`：当前证据无法支持可靠回答，或请求不在允许范围内。
- `检索不可用`：服务未能取得受治理的证据，因此不会生成回答。该状态不同于“证据不足”，可以保留原问题并稍后重试。
- `已取消`：服务已收到取消请求；草稿和已选附件会按当前提交阶段保留，以便调整后重试。
- `回答失败`、`服务不可用`：错误信息会隐藏服务端路径、凭据和模型内部信息。可以保留原问题并稍后重试；健康检查恢复前提交按钮保持禁用。

网络中断后，客户端会进行有限次数的状态查询，不会无限重试。若提交结果暂时不确定，使用原问题重试会沿用同一请求身份，避免重复生成和重复计费。

## 不支持的能力

技术问答不提供以下能力：

- 读取或扫描 Y3 项目目录、工作区或任意本地文件。
- 自动修改代码、生成可应用补丁、保存项目、构建或发布地图。
- 选择模型、供应商或自带 API Key（BYOK）。
- 切换到其他 Y3 编辑器版本或基于未发布分支推断行为。
- 绕过服务端知识审核、配额、可靠性门禁或安全限制。

问答内容应作为技术排查依据使用。涉及线上数据、资产发布或不可逆操作时，仍需人工核对引用和实际项目状态。
