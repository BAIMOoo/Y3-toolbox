# 大厅配置使用说明

`大厅配置` 用于从选定的 Y3 源码项目读取并编辑 `match.json` 与 `dungeon.json`，只写回这两个大厅配置文件，不修改项目中的其他内容。

## 打开项目

进入 `大厅配置` 后，点击“选择 Y3 项目”，在系统目录选择器中选择 Y3 源码项目目录。

应用会校验项目中的大厅配置文件：

- 如果已有 `match.json` / `dungeon.json`，会载入当前配置。
- 如果文件不存在，会创建待写入的新配置草稿。

## 编辑范围

工作区支持：

- 副本进入设置：公开进入、私人进入、房间容量、允许中途加入时间。
- 匹配设置：参与匹配、阵营人数、分数段扩散时间、机器人兜底时间、分数段与最低真人数。
- 快捷预设：必须凑满真人、定时机器人补位、按分数段匹配。
- 校验与 JSON 预览：右侧检查面板展示问题、`match.json` 和 `dungeon.json` 预览。

## 保存前检查

写入前应用会要求确认：

- 已自行备份项目。
- 已完全关闭 Y3 编辑器。
- 当前配置没有阻止保存的错误。

工具不会创建持久备份。Y3 编辑器运行时会用内存中的旧配置覆盖外部修改，因此请先关闭编辑器再保存。

## 安全边界

- 只读取所选项目的大厅配置。
- 只写入 `match.json` 和 `dungeon.json`。
- 写入前会做校验、预览和确认。
- 遇到项目文件被外部修改时，保存会按版本冲突提示失败，避免覆盖他人刚写入的配置。

## 注意事项

- 大厅配置只支持桌面版；Web 模式没有本地项目访问能力。
- 切换项目或关闭应用时，如果有未保存修改，会要求确认。
- 保存成功后，仍建议在 Y3 编辑器里复核大厅行为。
