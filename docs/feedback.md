# 反馈使用说明

`反馈` 是工具箱中的独立入口，主要用于接收 Y3 工具箱相关的 Bug 和功能建议。它不依赖 Agent 任务中心或技术问答，也不提供工单号、状态追踪链接或处理进度承诺。

## 提交范围

- `遇到了 Bug`：描述你在工具箱中遇到的问题。
- `有功能建议`：描述你希望工具箱改进的地方。

Y3 编辑器相关问题也可以提交，但不保证及时处理。请避免提交包含敏感信息的项目内容、账号凭据或本地文件路径。

## 必填内容

提交时只需填写：

- 反馈类型。
- 标题：Bug 用一句话概括问题，建议用一句话概括改进。
- 主描述：Bug 描述发生了什么；建议描述希望怎么改进。

其余字段放在“补充信息（可选）”中，留空也可以提交。

## Bug 附件

只有提交 Bug 时可以添加截图或日志：

- 支持日志、Trace、文本或 JSON：单个文件不超过 2 MiB。
- 支持 PNG、JPEG、WebP 截图：单张不超过 8 MiB。
- 每次最多 5 个附件，总大小不超过 16 MiB。
- 空文件、重复文件、包含本地路径的文件名和不支持的格式会被拒绝。

附件只用于本次显式反馈，不会授予服务访问项目目录或其他本地文件的能力。

## 隐私说明

提交时客户端只会附带固定范围内的元数据，不会上传：

- 本地路径。
- Token 或凭据。
- 项目内容。
- 设备指纹。

提交成功只表示反馈已收到，不会返回工单号或跟踪标识。

## 提交状态与草稿保留

- `提交中…`：正在校验、上传附件或提交。
- `反馈已收到`：提交成功，已清空当前草稿。
- 可重试失败：草稿和已选附件会保留，可以直接重试。
- 不可重试失败：通常是内容或附件不符合规则，请按提示修改后重新提交。

网络中断或提交结果不确定时，不要反复提交同一个问题，避免重复上传；可稍后重试。
